Wie bekomme ich einen Token?
  1. Geh zu airtable.com/create/tokens
  2. Klick „Create new token"
  3. Name: z. B. „Saalplan-App"
  4. Scopes: data.records:read + data.records:write
  5. Access: „Munich Watch Fair - Standplan" auswählen
  6. Token kopieren und hier einfügen

Hinweis: Der Token wird nur lokal in deinem Browser gespeichert, nie ans Internet geschickt — außer an Airtable selbst.
